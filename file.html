file data

Files uploaded to the site should be in the following JSON format: 

                     
            [
               {
                  "time":   [float]
                  "thrust": [float]
               },
               {
                  "time":   [float]
                  "thrust": [float]
               },
               {
                  "time":   [float]
                  "thrust": [float]
               },
               ...
            ]

Where the time values represent the point at time (in seconds) where the thrust was measured, and thrust represents the thrust in newtons recorded at that point in time.
